# archlinux-script-install

Набор автоматизированных скриптов для чистой установки и настройки **Arch Linux (UEFI + Btrfs + Штатное ядро `linux` + KDE Plasma 6 + Wayland)** под современные игровые ноутбуки (на примере **Acer Nitro V15-51**).

> **ВНИМАНИЕ (Дисклеймер):** Скрипты созданы автором под собственные нужды и конкретное оборудование (**Acer Nitro V15-51**). Автор не несёт ответственности за последствия их использования на других системах.

## Состав репозитория

| Файл | Назначение | Где запускается |
| :--- | :--- | :--- |
| **`base.sh`** | Разметка диска (`cfdisk`), субтома Btrfs (`@`, `@home`, `@snapshots`, `@var_log` с `noatime` и `zstd:1`), установка штатного ядра **`linux`** и **`linux-headers`**, автозапуск `chroot.sh`, размонтирование и запрос перезагрузки. | Live-образ Arch Linux (`root`) |
| **`chroot.sh`** | Настройка локалей и времени, ускорение `pacman`/`makepkg`, установка **KDE Plasma 6**, графики Intel (`mesa`, `intel-media-driver`), ZRAM (`zstd`), лимита логов `journald` (150 МБ), твиков `sysctl` (**CAKE + BBR**, `split_lock_mitigate=0`, `max_map_count`), отключение энергосбережения Wi-Fi (`wifi.powersave = 2`), правила `udev` (`ntsync` + NVMe `none`), блокировка `iTCO_wdt`, профиль Konsole **`Newbl1nk` (10pt)**, **`Fish`** (левый индикатор времени мин/сек), **`Starship`**, **`.nanorc`**, `yay-bin` и загрузчика GRUB. | Запускается автоматически из `base.sh` |
| **`menu.sh`** | Интерактивное меню пост-установки с индикацией выполненных этапов `[✓]` и обходом кэша CDN. | Установленная система (пользователь) |
| **`nvidia.sh`** | Установка драйверов **`nvidia`**, **`nvidia-prime`** (`prime-run`), Vulkan, VA-API, настройка Early KMS в `mkinitcpio`, параметров Wayland в GRUB, служб сна, **Dynamic Boost** (`nvidia-powerd`) и `nvidia.hook`. | Установленная система (пользователь) |
| **`apps.sh`** | Установка игровых и повседневных программ (`steam`, `gamemode`, `libreoffice-fresh-ru`, `vlc`, `qbittorrent`, `yt-dlp`, `ffmpeg`), исключение Steam из KDE Baloo, создание враппера **`nvgame`** (кэш шейдеров NVIDIA и DXVK на **10 ГБ**) и настройка буфера звука PipeWire. | Установленная система (пользователь) |
| **`damx.sh`** | Установка драйвера `linuwu_sense` (с патчем `strscpy`) и **Div Acer Manager Max (DAMX)** из локального архива в `~/Документы` (управление кулерами, профилями и лимитом заряда батареи 80%). | Установленная система (пользователь) |
| **`verify_arch.sh`** | Автоматическая диагностика всех **15 ключевых узлов** системы после установки и перезагрузки. | Установленная система (пользователь) |

## Готовые команды для запуска в терминале

### 1. Базовая установка и KDE Plasma 6 (из Live-образа Arch Linux)
Подключитесь к интернету (через `iwctl` или кабель) и выполните:
```bash
curl -fsSL "https://slemen.github.io/Archlinux/base.sh?t=$(date +%s)" -o base.sh && chmod +x base.sh && ./base.sh
```

#### Памятка по разметке диска в `cfdisk` (строго 2 раздела по порядку):

| Номер раздела | Тип раздела (`Type`) | Рекомендуемый размер | Назначение |
| :---: | :--- | :--- | :--- |
| **1** | `EFI System` | `512M` – `1G` | Загрузочный раздел `/boot/efi` (FAT32) |
| **2** | `Linux filesystem` | Всё оставшееся место | Основной раздел **Btrfs** (сжатие `zstd:1`, для swap используется ZRAM) |

---

### 2. Интерактивное меню пост-установки (после перезагрузки в KDE)
После входа в KDE Plasma откройте Konsole и запустите единое меню:
```bash
curl -fsSL "https://slemen.github.io/Archlinux/menu.sh?t=$(date +%s)" -o /tmp/menu.sh && bash /tmp/menu.sh
```

## Полезная шпаргалка после установки

* **Параметры запуска игр в Steam (NVIDIA + GameMode + кэш шейдеров 10 ГБ):**
  ```text
  nvgame %command%
  ```
* **Проверка работы дискретной видеокарты NVIDIA (`nvidia-prime`):**
  ```fish
  prime-run glxinfo | grep "OpenGL renderer"
  ```
* **Кнопка Nitro:** В *Параметры системы KDE → Клавиатура → Комбинации клавиш* добавьте команду `/usr/bin/DAMX` и назначьте клавишу Nitro.
